# Reglas de Trabajo Autónomo (Feria Mágica del Juguete)

## Modo de Ejecución 100% Autónomo (Sin pedir confirmación constante)

1. **Acción Directa:**
   - Cuando el usuario solicite un cambio, corrección, diseño o integración de assets, implementarlo de inmediato de principio a fin.
   - NO preguntar "¿quieres que lo haga?" o pedir confirmación previa; proceder a editar los archivos, compilar y verificar.

2. **Flujo de Entrega Automático:**
   - Realizar los cambios de código o assets necesarios.
   - Ejecutar `npm run build` para validar que no haya errores de TypeScript ni compilación.
   - Hacer `git add -A`, `git commit` y `git push origin main` junto con `git push origin main:prueva`.
   - Informar al usuario de forma clara y concisa los resultados y cambios realizados.

3. **Cuidado de Assets y Estilos:**
   - Mantener siempre la estética 2D de fantasía navideña estilizada y el rendimiento óptimo para dispositivos táctiles.
